# 🌱 Quota Garden

A cute, aesthetic dashboard for tracking AI model quotas across multiple accounts.

## Features

- Track multiple accounts
- Separate Gemini and shared Claude + GPT quota pools
- One-click **Mark exhausted**
- Live reset countdowns
- Automatic local storage
- Best-account recommendation
- Responsive dark UI

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

This first version stores data locally in your browser. Future versions can add Supabase sync and browser-extension automation.
